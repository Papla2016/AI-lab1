Верните ТОЛЬКО один корректный JSON-объект без Markdown и без дополнительного текста.

Строго соблюдайте типы полей:

{
  "answer": "одна строка текста",
  "citations": [
    {
      "source": "имя файла",
      "chunk_id": "идентификатор"
    }
  ],
  "confidence": "low",
  "insufficient_context": false
}

Правила:
- `answer` ОБЯЗАТЕЛЬНО должен быть JSON-строкой.
- `answer` НИКОГДА не должен быть массивом или объектом.
- Неверно: `"answer": ["текст"]`
- Правильно: `"answer": "текст"`
- `citations` всегда является массивом объектов.
- `confidence` принимает только одно из значений: `"low"`, `"medium"` или `"high"`.
- `insufficient_context` является boolean: `true` или `false`.
- Если контекста недостаточно:
  - `answer` содержит строку о недостаточности данных;
  - `citations` должен быть пустым массивом `[]`;
  - `confidence` должен быть `"low"`;
  - `insufficient_context` должен быть `true`.
- Если ответ дан по контексту:
  - `insufficient_context` должен быть `false`;
  - должна быть как минимум одна citation.
- Каждая citation должна точно соответствовать `source` и `chunk_id` одного из фрагментов CONTEXT.
- Не создавайте отсутствующие `source` или `chunk_id`.
